# Cinema-Buffet-Sales
Cinema buffet sales project

🎬 Cinema Buffet Sales - C# Web Form Project 🎉
Welcome to Cinema Buffet Sales! This simple yet powerful C# Web Form application allows you to easily manage buffet and ticket sales in the cinema. Whether you are selling popcorn or tickets for the latest movie, this system handles it all effortlessly.

🍿 Features
Three Interactive Screens: Seamless transition between product selection, pricing and cash register screen.
Real-Time Total Calculation: Instant total amount calculation based on the selected product quantity.
Product List:
🥤 Corn: 50 units
🍵 Tea: 20 units
💧 Water: 10 units
🎟️ Ticket: 80 units
Cash Integration: Calculated total is automatically added to the cash register with each transaction.
Clear & Restart: A handy reset button clears the lists and allows for an easy restart by focusing on the first item.

🎯 How It Works:
Quantity Entry: On the first screen, enter the quantities of the four available products (corn, tea, water, and tickets).
Price Display: The next screen shows the prices of each product.
Total Calculation: The third screen shows the total amount by multiplying the quantities by the prices.
Cashier: The calculated total is added to the cashier, allowing you to track daily sales quickly and easily.

🚀 Why You Will Love It:
This project is not just about buffet sales; it focuses on efficiency and ease of use! Built using basic C# tools, this project offers a fast, responsive, and enjoyable experience. Whether you are managing large crowds or just selling a few tickets, Cinema Buffet Sales will always help you.
